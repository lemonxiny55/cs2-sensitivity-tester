# CS2 Sensitivity Tester

一个离线运行的 CS2 灵敏度盲测网页。它围绕当前游戏内灵敏度生成 5 个候选值，并通过小目标定位、移动目标跟枪和反应点击，给出推荐灵敏度与可复测区间。

## 解决的问题

在 CS2 中调整灵敏度通常依赖手感，且一次练习很难公平比较多个档位。本项目将候选灵敏度随机且隐藏地轮换，记录准确率、完成速度、轨迹偏离和稳定性，减少预期偏差，帮助玩家缩小更适合自己的灵敏度范围。

项目模拟所选 CS2 分辨率的虚拟画布、画幅和黑边/拉伸方式，并在测试开始时请求浏览器全屏和鼠标锁定。浏览器不能切换 Windows 的物理显示器输出分辨率，也不能复刻 CS2 的 FOV、地图、模型或网络环境。

## 主要功能

- 基于当前 CS2 灵敏度生成 5 个相邻候选值，统一精确到两位小数。
- 提供小目标定位、移动目标跟枪、反应点击三类盲测项目。
- 提供 4:3、5:4、16:9、16:10 常见 CS2 分辨率预设；非 16:9 可选黑边保留比例或拉伸铺满。
- 使用虚拟分辨率画布，全屏后按所选分辨率的坐标系与缩放方式显示测试区。
- 请求全屏与 Pointer Lock；失焦、窗口过窄或鼠标锁定失效时暂停并重启当前项目，避免无效样本。
- 过滤异常大的单帧鼠标移动与重新锁定后的首个移动事件，减少准星瞬移。
- 输出推荐值、建议区间、置信度、候选对比与本地历史；可清除历史并导出 JSON。

## 安装方法

项目没有第三方运行依赖。在项目根目录运行本地 HTTP 服务，可获得更稳定的全屏和鼠标锁定行为：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:4173`。

也可以直接打开 `index.html`，但部分浏览器会限制本地文件的全屏或鼠标锁定 API。

运行自动化测试需要 Node.js 18 或更高版本：

```powershell
npm test
```

## 使用方法

1. 输入当前 CS2 游戏内灵敏度，范围为 `0.10` 或更高；DPI 可选，仅作记录。
2. 选择与 CS2 相同的分辨率；使用非 16:9 分辨率时，选择黑边或拉伸方式。
3. 点击“进入测试”，并在浏览器提示时允许全屏和鼠标锁定。
4. 完成 15 个短项目。测试期间不会显示当前候选灵敏度。
5. 在结果页查看推荐值、建议区间、置信度和候选对比；低置信度结果建议休息后复测。
6. 使用“导出 JSON”保存本地历史，或使用清除按钮删除浏览器内的全部历史。

## 输入输出示例

输入：

```text
当前 CS2 灵敏度: 1.20
DPI: 800
分辨率: 1280 x 960
显示方式: 拉伸铺满
```

对应的候选灵敏度：

```text
0.91, 1.06, 1.20, 1.34, 1.49
```

结果页可能显示：

```text
推荐灵敏度: 1.20
建议区间: 1.06 - 1.34
置信度: 中
```

导出的 JSON 含导出时间和浏览器本地历史；每条会话包含基准灵敏度、可选 DPI、推荐值、建议区间、置信度、综合分和候选得分。实际结果取决于当次表现，上述结果仅用于说明格式。
