# CS2 Sensitivity Tester

一个离线运行的 CS2 灵敏度盲测网页。它以你当前游戏内灵敏度为中心生成 5 个候选值，通过四目标、跟枪、六目标和单球点击四类任务，给出推荐灵敏度与可复测区间。

## 解决的问题

在 CS2 中调整灵敏度通常依赖手感，且一次练习很难公平比较多个档位。本项目把候选灵敏度随机且隐藏地轮换，记录准确率、完成速度、轨迹偏离和稳定性，减少预期偏差，帮助玩家缩小更适合自己的灵敏度范围。

项目模拟所选 CS2 分辨率的虚拟画布、画幅和黑边/拉伸方式，并在测试开始时请求浏览器全屏和鼠标锁定。浏览器不能切换 Windows 的物理显示器输出分辨率，也不能复刻 CS2 的 FOV、地图、模型或网络环境。

## 主要功能

- 围绕当前 CS2 灵敏度生成 5 个相邻候选值，统一精确到两位小数。
- **真实标定**：游标与目标在角度空间运动，按 CS2 的 `0.022°/count`（m_yaw/m_pitch）与 hor+ 视场模型（4:3 → 90°，16:9 → ≈106.3°）驱动 Three.js 第一人称相机；测试屏底部常驻标定栏。鼠标在工具里 1 count 的转角与游戏一致（要求系统指针速度 6/11 且无加速度）。
- **3D 靶场**：WebGL 渲染的第一人称封闭训练房（浅色菱纹地板 + 深色棋盘高墙 + 暗色天花板，Aimlab 式包裹感，房间宽 ±30m、纵深至 -40m），准星固定居中、世界随视角转动，与 CS2 的视觉流一致；目标为随机深度（16–28m）、全部生成在视平线上方（不会出现在地板上）的球体，命中判定按角半径计算，比 2D 矩形更贴近真实弹道。Three.js 已本地 vendor（`vendor/`），离线可用。
- **四类练枪任务**：**四目标**（场上恒定 4 颗等大的球聚成紧凑球群、中距离，命中一颗立即补一颗，考微调与转火节奏）、**跟枪**（按住左键并贴住急停变向的蓝色球，头顶满条才递减、脱靶或松键条暂停，减空换球，球大小随机 2.4–4%）、**六目标**（6 颗更小的球铺满中等范围，命中随机补位）、**单球点击**（小球延迟出现、尽快点击，命中刷新下一个，兼任反应测量）。
- **初测 + 复测确认（四大环节制）**：不设暖手轮，点开始直接进入初测——**四目标 → 跟枪 → 六目标 → 单球**四个环节依次进行，每个环节内 5 个候选各测一轮、先后随机（环节固定给出一致的测试节奏；档位随机让冷手/疲劳噪声不系统偏向任何档位），每个环节结束弹一次本环节成绩（命中率、平均每球耗时）。初测共 20 轮；前二名按同样四大环节各加测一轮（8 轮）做**复测确认**——初测排名在复测中复现才算站稳，被推翻则置信度降级。复测开始前弹窗提示前二名，共 28 计分轮、约 15 分钟。
- **拉枪轨迹分析**：记录准星角度轨迹，按业内口径计算启动延迟（≥127°/s 视为启动）、方向倾向与真实过冲/欠冲率（停点按目标角半径归一化，越过边界才计入）、二次微调幅度与微调准确度、路径效率与首发命中率；结果页展示分档指标表与拉枪速度曲线。
- **基于曲线拟合的推荐**：对 5 档综合得分做二次拟合，取其峰值作为推荐值；置信度综合峰值位置、档位平坦度与头名差距给出高/中/低，并提示各档差异是否显著。
- **数据卫生**：反应任务过滤 <100ms 的抢跑点击；实时监测帧率并在 HUD 显示 FPS 与 1% low，平均帧率 <45、最大单帧 >250ms 或 1% low <20 FPS 任一不达标的轮次自动标记并重测一次（均值会被时长稀释，1% low 与最大单帧专门捕捉卡顿尖刺），避免卡顿污染得分。
- 跟枪目标为急停变向横移（10–14°/s，每 0.4–1.1s 随机急停，30% 概率停顿后反向，附带 ±1.5° 上下浮动），打满 N 球完成本轮；点击类任务的球为等大设计，不再随命中递缩。
- 提供 4:3、5:4、16:9、16:10 常见 CS2 分辨率预设；非 16:9 可选黑边保留比例或拉伸铺满。
- 使用虚拟分辨率画布，全屏后按所选分辨率的坐标系与缩放方式显示测试区。
- 请求全屏与 Pointer Lock；失焦、窗口过窄或鼠标锁定失效时暂停并重启当前项目，避免无效样本。设置面板常驻**鼠标原始输入**状态徽章（首次开始测试时自动检测 unadjustedMovement）：启用时标定栏显示 RAW INPUT；降级时徽章变黄提示关闭“提高指针精确度”，标定栏如实显示 OS CURVE，且导出数据会记录该状态。
- 过滤异常大的单帧鼠标移动与重新锁定后的首个移动事件，减少准星瞬移。
- 有 DPI 时实时提示 cm/360，结果页对比基准与推荐灵敏度的转身距离。
- **可回溯的测试报告**：每场测试自动生成完整报告（推荐值、相对起始值 %、eDPI、候选对比、复测确认、拉枪分析与逐轮明细），在结果页点击「查看完整报告」或在历史记录里点击任意一场即可回看当时的数据。
- 输出推荐值、建议区间、置信度、候选对比（三维 + 综合）、**分任务偏好解读**（各任务最优档相互印证或方向冲突时给出取值建议）、拉枪分析与本地历史；结果页内置“指标说明”面板解释每项统计口径；历史页按置信度加权给出**同基准的多场次建议**，并显示收敛趋势；可清除历史并导出 JSON（含标定快照与逐轮明细）。

## 安装方法

项目没有第三方运行依赖。**推荐双击项目根目录的 `start.cmd`**：自动用 Node（或 Python）启动本地服务并打开浏览器，关闭命令行窗口即停止。

也可以手动运行（任选其一）：

```powershell
node serve.js
```

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后在浏览器打开 `http://127.0.0.1:4173`。

> 不要直接双击 `index.html`：浏览器会拦截 `file://` 协议下的模块脚本（CORS），页面会显示一条提示而无法进入测试。请通过上面的本地服务打开。

运行自动化测试需要 Node.js 18 或更高版本：

```powershell
npm test
```

## 使用方法

1. 输入当前 CS2 游戏内灵敏度，范围为 `0.10` 或更高；DPI 可选，输入后会实时显示 cm/360。
2. 选择与 CS2 相同的分辨率；使用非 16:9 分辨率时，选择黑边或拉伸方式。
3. 点击“开始测试”，浏览器随即进入全屏并锁定鼠标，直接开始暖手轮（候选档位已隐藏，测试期间不会显示）。为保证标定准确，请将 Windows 指针速度保持在 6/11 并关闭鼠标加速。
4. 点「开始测试」后直接进入初测：5 个候选档位 × 四项任务共 20 轮随机交错（HUD 显示 初测 N/20）；初测结束弹窗提示前二名，点击“继续测试”进入复测确认（8 轮）。测试期间不会显示当前候选灵敏度。
5. 在结果页查看推荐值、建议区间、置信度、复测结论、候选对比与拉枪分析；点击「查看完整报告」可回看本次逐轮明细，低置信度或复测不一致时建议休息后复测。
6. 在历史记录中点击任意一场可打开当次完整报告；使用“导出 JSON”保存本地历史，或使用清除按钮删除浏览器内的全部历史。

## 输入输出示例

输入：

```text
当前 CS2 灵敏度: 1.20
DPI: 800
分辨率: 1280 x 960
显示方式: 拉伸铺满
```

对应的候选灵敏度：

```text
0.91, 1.06, 1.20, 1.34, 1.49
```

结果页可能显示：

```text
推荐灵敏度: 1.20
建议区间: 1.06 - 1.34
置信度: 中
基准 1.20 ≈ 43.3 cm/360° → 推荐 1.20 ≈ 43.3 cm/360°
```

候选对比矩阵展示“定位 / 跟枪 / 反应 / 综合分”四列得分，每列最优值高亮。综合分仅基于阶段 2 的完整深度测试；未晋级档位只显示阶段 1 的参考分，未测任务显示 —。拉枪分析表展示每个档位的启动延迟、方向倾向（明显欠冲 → 明显过冲五级）、真实过冲/欠冲率、微调幅度与路径效率，并绘制推荐档位的拉枪速度曲线（加速段 → 峰值 → 减速与停点）。导出的 JSON 含导出时间、标定快照（yaw/FOV）和浏览器本地历史；每条会话包含基准灵敏度、可选 DPI、推荐值、拟合峰值、建议区间、置信度、各任务类型排序、拉枪指标聚合与每轮明细（含阶段标记与轨迹指标）。实际结果取决于当次表现，上述结果仅用于说明格式。
